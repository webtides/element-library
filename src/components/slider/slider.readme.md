# Slider

`slider` lets you slide child elements

## How to use

### Installation

```sh
npm i --save @webtides/element-library
```

```js
import '@webtides/element-library/slider/define';
```

### Example

```html
<slider>
    <li class="item">1</li>
    <li class="item">2</li>
    <li class="item">3</li>
</slider>
```
