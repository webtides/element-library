# CarouselElement

`carousel-element` lets you slide child elements

## How to use

### Installation

```sh
npm i --save @webtides/element-library
```

```js
import '@webtides/element-library/src/components/carousel-element/carousel-element.js';
```

### Example

```html
<carousel-element>
    <div>1</div>
    <div>2</div>
    <div>3</li>
    <div>4</li>
</carousel-element>
```
