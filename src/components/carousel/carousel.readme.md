# Carousel

`carousel` lets you slide child elements

## How to use

### Installation

```sh
npm i --save @webtides/element-library
```

```js
import '@webtides/element-library/carousel/define';
```

### Example

```html
<carousel>
    <div>1</div>
    <div>2</div>
    <div>3</li>
    <div>4</li>
</carousel>
```
