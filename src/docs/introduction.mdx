# Introduction

`@webtides/element-library` is a collection of pre-built custom elements based on [`@webtides/element-js`](https://github.com/webtides/element-js), with a focus on performance and accessibility.

It gives you a starting point for rapidly building UIs without having to re-implement the same elements over and over again — accordions, tabs, dropdowns, sliders, form fields, scroll helpers, and more.

> **Work in progress** — the elements are subject to major (and breaking) changes until the 1.0 release. Until then, we recommend pinning versions instead of relying on semantic versioning.

## What's in the box

- Native custom elements, framework-agnostic — use them in plain HTML, or alongside React, Vue, Svelte, etc.
- Tree-shakable: import only the components you need, or register them all at once.
- Built-in accessibility considerations and keyboard interactions where applicable.
- A Custom Elements Manifest and JetBrains web-types ship with the package for editor autocomplete.
